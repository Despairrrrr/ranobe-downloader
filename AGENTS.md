# Скачиватель ранобэ

## Описание
программа должна по ссылке подобного типа "https://ranobelib.me/ru/book/kage-no-jitsuryokusha-ni-naritakuteln?section=chapters"
перейти по ссылке и собрать текст из нужной главы сохраняя все в файл формата '.fb2'.

## Подробный цикл использования приложения
1) после запуска приложения на экране появляется окно, в котором есть пустое место для ссылки на ресурс с главами и пустое место для указания интересующей главы.
2) после указания ссылки и номера главы программа переходит по данной ссылке и переходит в данном ресурсе по нужной главе. Например, если пользователь указал  в качестве номера главы 1, то программа нажимает в перечне глав ищет первую главу, переходит по ней и достает весь текст из ресурса.
3) После она просто сохраняет этот текст в fb2 файле называя файл номером главы
