# Скачиватель ранобэ

## Описание
GUI-приложение для скачивания ранобэ с ranobelib.me/cdnlibs.org и сохранения в формат FB2.
Также доступен скрипт для склейки глав тома в один FB2-файл с содержанием и обложкой.

## Структура проекта
```
├── main.py                  — точка входа, запуск PyQt6 приложения
├── ui/
│   └── main_window.py       — главное окно: ввод ссылки, номера главы, кнопка скачивания
├── scraper/
│   └── api_client.py        — работа с API cdnlibs.org: поиск глав, скачивание контента, парсинг
├── exporter/
│   └── fb2.py               — формирование FB2-файла с встраиванием картинок
├── merge_fb2.py             — CLI-скрипт склейки глав тома в один FB2
├── launch.sh                — запуск GUI-приложения
├── merge.sh                 — запуск скрипта склейки
└── requirements.txt         — зависимости: PyQt6, requests, lxml
```

## Зависимости
- Python 3.10+
- PyQt6, requests, lxml

## Запуск
- GUI: `./launch.sh`
- Склейка тома: `./merge.sh <номер_тома>` (например `./merge.sh 3`)

## Цикл использования
1. Запустить `./launch.sh`
2. Вставить ссылку на ранобэ (например `https://ranobelib.me/ru/book/kage-no-jitsuryokusha-ni-naritakuteln?section=chapters`)
3. Указать номер тома
4. Указать номер главы (или оставить пустым для скачивания всех глав тома)
5. Нажать «Скачать»
6. Файлы `.fb2` сохраняются в папку `output/`

## Функционал
- Скачивание одной главы по номеру
- Скачивание всех глав тома (пустое поле главы)
- Мерж подглав с одинаковой целой частью (главы 0 и 0.1 → один файл)
- Имя главы в заголовке FB2
- Поддержка двух форматов контента от API: HTML и TipTap JSON
- Встраивание картинок в FB2
- Склейка тома в один FB2 с оглавлением и обложкой (`merge_fb2.py`)
- Потокобезопасное обновление GUI через pyqtSignal
