# Ranobe Downloader

Скачиватель ранобэ с ranobelib.me в формат FB2 с PyQt6 GUI.

## Возможности
- Скачивание отдельной главы или всех глав тома
- Мерж подглав (например главы 0 и 0.1 сохраняются в один файл)
- Имя главы в заголовке FB2-файла
- Встраивание картинок в FB2
- Склейка всего тома в один FB2-файл с оглавлением и обложкой

## Требования
- Python 3.10+
- Linux (тестировалось на)

## Установка и запуск
```bash
git clone https://github.com/username/ranobe_downloader.git
cd ranobe_downloader
./launch.sh
```
При первом запуске автоматически создастся виртуальное окружение и установятся зависимости.

## Использование
1. Вставьте ссылку на страницу ранобэ
2. Укажите номер тома
3. Укажите номер главы (или оставьте пустым для скачивания всех глав)
4. Нажмите «Скачать»

### Поддерживаемый формат ссылки
Работает только с **ranobelib.me**. Формат:
```
https://ranobelib.me/ru/book/<slug>
```

**Примеры:**
```
https://ranobelib.me/ru/book/kage-no-jitsuryokusha-ni-naritakuteln?section=chapters
https://ranobelib.me/ru/book/mushoku-tensei-lyutyy-kolsennik?section=chapters
https://ranobelib.me/ru/book/overlord?section=chapters
```

Параметр `?section=chapters` опционален — приложение само определит главы.

## Склейка тома в один FB2
```bash
./merge.sh <номер_тома>
```
Соберёт все скачанные главы указанного тома в один файл `том<номер>.fb2` с оглавлением и обложкой.

**Пример:**
```bash
./merge.sh 3   # соберёт том3.fb2 из всех том3_глава*.fb2
```

**Обложка:** чтобы обложка попала в томник, положите JPG-файл с именем, начинающимся на `том`, рядом с FB2-файлами глав. Например `том3.jpg`. Скрипт автоматически найдёт её по маске `том*.jpg`.

**Требования к файлам глав:** файлы должны называться `том<номер>_глава<номер>.fb2` и находиться в одной папке.

```
├── launch.sh                — запуск приложения
├── merge.sh                 — запуск склейки
└── requirements.txt         — зависимости
```
